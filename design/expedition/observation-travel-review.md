# 新远征流程理解：观测、反扑、航行与持续地球防御

> **用户回复更新：** 已明确“只揭露被观测星球，其他星球各自观测”。下文初审中的这一歧义已解决；其余时间和结算细节仍按建议解释标注。最终综合口径见 [理解报告](observation-expedition-understanding.md)。

日期：2026-09-10。性质：需求理解与边界审查，**不是已实施功能，也不是所有建议已经获得用户确认**。本轮仅只读检查当前 main/battle 和旧设计，未运行游戏、未改生产代码/原档/旧图谱。此前真实通关档的自动保护副本保持原样；本轮不推进存档库。

## 1. 已明确的新要求

1. 存档库暂时不做，不能再把它放在玩法实现的前置里程碑。
2. 望远镜是醒目的科技节点。研究后，玩家点击自己选择的星球，另花大量科研执行观测；不能再把科技研究等同于六母巢全部揭露。
3. 观测引发大量敌方母舰反扑，默认 5 波，波数可配置；反扑以规模制造压力，单体数值保持平缓。此期间允许建造自己的母舰。
4. 完成反扑后披露母巢。之后玩家母舰出航，默认使用“5 波时长”，可配置，途中有敌方母舰阻击。
5. 远征过程中地球仍承受持续、逐渐增强的袭击。地球不应因玩家看向另一星球而暂停、无敌或只留下资源收入。
6. 抵达后能看到真实母巢建筑和敌军；第一版所有星球使用同一套异星月球母巢与通用兵营，保留可扩展类型，不先做六套差异。普通敌机优先升级成异星造型。
7. 科技树按已经确认的大小节点、醒目标志与 hover 详情形式推进；本审查不改已确认图谱。

“默认 5 波”有两个不同语义，下面必须分别定义，不能用同一个计数器代替。

## 3. 两套时间语义

### 3.1 建议：观测的 5 波是 5 次真实击退结算

用户描述为“反扑五波，完成后披露母巢”。建议按实际战斗结算理解：

- `observation_waves_required=5` 是需要完成的波数，不是倒计时段数。
- 每波有固定刷怪窗口，例如单独配置 `observation.spawn_window_seconds`；窗口结束只停止该波继续派兵。
- 这一观测波所分配的母舰/敌群及仍有杀伤能力的弹体得到处理后，才增加 `observation_waves_cleared`。可以设定敌舰合法撤退算击退，但必须有可见规则，不能默删冒充击毁。
- 下一波的补给间隔单独配置。提前杀光仍等派兵窗口结束；残敌未清则继续防御，不能“时间到第 5 波”便揭露。
- 只统计带本次 `observation_id/wave_id` 的事件；地球常态敌人若并行，不能使观测永远无法清场，也不能误把常态波清掉算观测成功。

若五波都用 30 秒刷怪窗口，只有派兵窗口的合计下限为 **150 秒**。真实观测用时还包括各波清场和明确配置的间隔，不能保证精确 150 秒。

**需确认：** “反扑波完成”是否要求本波敌母舰也被击毁/击退，还是只需消灭它释放的普通敌群？当前旧机制的常规过波并不要求存活母舰全部死亡，不能直接沿用而不说明。

### 3.2 建议：航行的“5 波时长”采用 5 个固定波周期

为给“到达时间可配置”一个稳定含义，建议使用独立时间单位：

`travel_duration = travel_period_count × travel_period_seconds`

- `travel_period_count` 默认 5；`travel_period_seconds` 明确为固定游戏秒，不引用某次实际清场花了多久。
- UI 写“航行 5 个周期 · 总计 X 秒”，避免误写“必须击退 5 波才能抵达”。该解释仍需用户最终确认。
- 例如选定一个周期 30 秒，5 周期就是 150 个游戏秒；若设计决定包含固定补给段，应先把周期明确设为 46 秒等固定值。不能默认从当前“30 秒刷怪 + 不确定清场 + 16 秒补给”凑一个隐藏周期。
- 阻击可以每周期安排一批或按独立时间表生成。它们增加战斗压力，但不靠“杀完才走”改变航行倒计时。
- 主动暂停时全部世界与航行同时暂停；2 倍速时都按同一游戏时间倍率前进。切到地球、星图或第一人称不改变航行进度率。

如果用户真正想要“途中也要实打五波，全部击退才抵达”，那是另一种合理玩法，但不再是固定航时。报告不能把这两种版本同时承诺。

### 3.3 当前计时实现不能原样扩成多世界

当前 [main.gd](../../scripts/main.gd) 第 253–269 行的经济和补给使用 `delta * speed`；[battlefield.gd](../../scripts/battlefield.gd) 第 351–374 行，移动/战斗用 `min(delta,0.06)*speed`，派兵窗口用未截断的 `delta*speed`。单帧大停顿时已有“窗口进度”和移动积分的不同口径。

未来地球、观测、航行、抵达战斗应消费同一个战役游戏时钟；需要防穿透的移动用子步处理，不能让后台世界因视图帧率不同少推进时间。此处是实现约束建议，本轮没有修代码或性能测量。

## 4. 叠加关系：已明确与建议解释分开

**已明确：** 玩家母舰出航后，地球袭击与航路阻击要并存；玩家切回地球时，远征不能被悄悄冻结。抵达后的母巢战斗也不能让地球停止受袭。

**尚有歧义：** 观测反扑发生在哪里、是否在地球常态袭击上再额外叠加一套五波，用户没有给出完全精确的调度规则。

建议第一版采取以下解释，作为待确认方案：

| 阶段 | 地球战斗 | 远征战斗 | 原因 |
|---|---|---|---|
| 观测反扑 | 本次五波成为地球袭击模板的临时强化，不另开隐形第二套地球波 | 尚未启航，可建/整备己方母舰 | 玩家能明确对应“正在完成观测第几波”，防止同地球双调度意外翻倍 |
| 观测完成、整备 | 恢复地球常态缓增袭击 | 己方母舰整备 | 星球披露保持，不会因等待而重新锁定 |
| 航行 | 常态缓增袭击继续 | 航路敌母舰阻击 | 两处独立目标、计数和伤害，不能同一次生成事件在两处各复制一份 |
| 抵达 | 常态缓增袭击继续 | 真实母巢建筑/兵营与驻军 | 至少两个有效模拟区域，当前视角只决定展示与交互 |

如用户希望反扑与常态地球波叠加，应显式显示两类事件，并为总预算设可解释的组合公式；不能每处直接调用当前 `start_wave()`，共用一个 game.wave 或通过多个 `_process` 重复发奖励。

观测期间“可造母舰”不自动等于已允许提前出航。建议只有本次目标披露完成、舰体制造完成且具备出航条件时才可派往该目标；玩家可以并行准备，不能在母巢坐标尚未确定时绕过观测流程。此处为建议，不是新增已确认门槛。

## 5. 状态与 125 波旧档边界

建议先明确逻辑状态，不要求本轮实施命名存档库或完整战斗快照：

```text
全局：望远镜未研究 → 望远镜已研究
每个星球：可选但母巢未知 → 已付费观测/防御中 → 母巢已披露
己方舰：可制造/整备 → 航行中 → 抵达作战 → 撤退/维修 → 可再出航
地球：常态防御 ↔ 观测反扑强化；远征期间仍独立推进
```

- `planet_id`、`observation_id`、`travel_id` 与各自波次/时间独立；任何一个区域的清场事件都要带来源。
- 旧 `wave=125`、`completed_waves=125`、`defense_time≈6495.94s` 和 28 项设置是既有投入/历史，保留；不能清零它们，也不能让观测第一波直接使用第 126 波的公式和历史满弹幕。
- 建议地球新持续袭击有单独的阶段二 elapsed/wave counter 与缓增曲线；反扑强度按观测开始时的独立基准锁定，五波只作小幅线性提升或仅增加构成/数量。
- “平缓”的准确生命、伤害和数量坡度要定参数。可写候选式 `H_i=H_start×(1+g_hp×(i-1))`、`D_i=D_start×(1+g_damage×(i-1))`，但不能把这里的 g 视作用户确认值。基准由明示难度配置定义，不随玩家临时穿脱装备实时追涨。
- 地球渐强不应每次切视角、重新点星球、打开科技树或重试观测就重置；反扑锁定基准不应在中途突然被地球下一常态波拉高。
- 旧八母舰仍保持已摧毁；新增反扑/阻击母舰使用新的战斗身份，不能把 `destroyed_fronts` 清空来复活旧任务、重复领取旧奖励。
- “阶段一完成”不再禁止新地球袭击，但也不等于阶段二最终完成。当前 main 的 `campaign_won` 和 battle 的 `_invasion_won` 会阻止生成并清空敌人，不能作为新流程的总开关。

**基线待确认：** “地球持续渐强”是从旧 125 波对应战力继续平滑增长，还是进入独立二阶段基础配置后增长？建议保留历史而启用独立可调基准；无论选哪种，都应在界面预告，不能无提示把旧存档代入新指数或把本来强大的防线全部贬值。

## 6. 切视角与抵达时的残留敌人

### 现状冲突

当前 `main._is_observing()` 把非地球 focus 当观察；`_world_is_paused()` 第 193 行因此返回 true。`_on_focus_changed()` 与 `_process()` 会同时暂停 battle、planet、game.tick。旧案用这种规则浏览漂亮星球合理，新案若沿用，玩家只需盯着远征视图就能让地球无敌，或切回地球便让航行不再受损。

建议仅主动全局暂停/明确暂停的模态停全部世界。普通切视角和 HUD 焦点不能改变战斗有效性。科技界面是否仍全局暂停需明确；它必须对所有世界一致，不能只暂停正在看的区域。后台可隐藏特效或减少显示开销，但不能删除敌人、阻止损伤或延迟到玩家切回才一次性判死。

### 航行到点不代表敌人消失

固定航时意味着可能在敌母舰或敌弹尚存时抵达。建议采取可解释的边界规则：

- 到达时停止本次旅行后续生成，冻结其派兵计划并转为抵达状态，不再加长航行倒计时。
- 能继续追击的存活敌舰/弹体保留 HP、UID、目标和奖励归属，接入抵达战区；是否所有大型母舰都可追随，需美术/战斗共同定义。
- 明确脱离追击距离的单位可以撤退退出，但不发击杀奖励；有可见演出/日志，不能借加载新场景瞬间清全场骗玩家。
- 抵达后的本地驻军按独立配额生成，不把带入的追兵再复制一批。下一轮观测/航行不重用旧 event ID。
- 地球那一侧的敌人完全不受远征抵达影响；不能调用当前 `_declare_invasion_victory()` 这种全局清场路径。

替代方案是最后一个周期停止增援并保证敌军主动撤离，然后准点进入新区域；这可降低首版状态转移成本，但同样需要明确表现与规则。**不建议**隐式要求清场才能抵达，同时仍声称固定五周期航时。

## 7. 科研、失败重试与多星观测的歧义

| 问题 | 已知范围 | 建议解释，尚需确认 |
|---|---|---|
| 望远镜研究费用 | 用户只明确是醒目科技 | 一次研究永久解锁“观测操作”；不再叠一个实体望远镜建筑费用 |
| 逐星观测科研 | 要点击目标花大量科研 | 对该星球的观测投资单独显示；金额尚未确定，旧70k总启动链不可继续引用 |
| 反扑前取消 | 用户未明确退款时机 | 尚未提交生成时可取消不扣；提交后为永久投入，避免反扑刷出后退费 |
| 反扑失败 | 未说明重试是否再交科研 | 建议已支付的该星观测资格保留，重试防御不再扣同笔科研；是否从0波重打单列配置/确认，不能在UI暗改 |
| 成功后的重复点击 | 未明确 | 已披露母巢永久保持，不再收费、不再重复发首次发现奖励 |
| 披露范围 | “点击任意星球观测…完成后母巢披露” | 推荐只披露所选星球，其它星球仍待各自观测；不是一次观测全部揭露。需根向用户明确此理解 |
| 同时观测多个星球 | 未明确 | 首版建议同一时间一个观测操作，其他可看详情不扣费；避免一次误点触发数套大反扑。并行可做后续规则，但不能当成已确认限制 |
| 观测与远征并行 | 地球和远征必须持续，但是否能远航时再观测另一星未明确 | 首版建议可排队准备，是否立即触发地球强化波需确认；不能为了省事暂停原远征 |
| 航行失败/撤回 | 未给损失与恢复规则 | 科技、已揭露坐标、已建母舰/工厂和永久蓝图保留；新的航行是否付补给、是否重走完整五周期另定。旧120秒免费修理只作为此前提案，不能宣称本轮重新确认 |
| 地球被毁时己方母舰仍活 | 用户未明确新失败边界 | 建议全局明确失败并停所有战区，避免无地球继续凭空获得后勤；如希望残存舰队重建家园，则是另一套更大玩法 |

科研支付和本次观测资格要作为一个事务；奖励/披露只提交一次。若失败允许重复反扑，普通波奖励是否可重复是平衡选择，但首次披露/首次补助不能被“退出再进”重领。至少按 observation_id/wave_id 记录结算，而不是按当前屏幕上显示的 1～5 数字发奖励。

本轮暂停存档库不妨碍把这些状态语义说明白；它不等于已经授权制作命名槽、迁移 UI 或任意时刻保存战斗。现有完整八母舰通关原件继续保护，未来测试也不直接覆写它。

## 8. 建议根在理解报告中优先说清的五个选择

1. **观测成功只揭露当前星球，还是一次揭露全部？** 推荐逐星，符合选择目标与单独科研投资。
2. **观测五波是否必须击退敌母舰本体？** 推荐有限配额真实结算；同时说明与地球常态波替换还是叠加。
3. **航行五波时长是否采用固定周期？周期含不含补给间隔？** 推荐独立固定游戏秒，到点进入抵达状态，残敌按追击/撤退处理。
4. **观测失败是否再次扣大量科研、是否保留已清波数？** 推荐已付资格保留，避免连续失败耗尽唯一启动科研；重试起点单独确认。
5. **地球新压力从旧125波继续，还是新阶段基准？** 推荐独立基准且明示，保留旧历史和实力；确定单体平缓仅约束反扑还是整个新阶段。
