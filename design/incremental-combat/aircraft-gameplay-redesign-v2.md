# EARTHWARD 敌我飞机玩法重设计

本案围绕地球防御增量玩法，建议重做九种我方飞机的攻击过程，建立十种普通敌军与三种 Boss 的战术职责，再据此确定模型、武器挂点和动画。目标是在相同资源与科技水平下，改变机型搭配能够明显改变战斗过程。以下新机制、解锁波次和数值均为原型建议，尚未实装或完成胜率验证。

## 现状诊断

现有版本已经有护甲克制、多目标射击、蓄能、支援猎杀和压制效果，但多数飞机仍共享同一种运动过程：接近目标，停在按武器家族确定的距离，再持续攻击。`_update_interceptor()` 只按动能、激光、导弹设置停靠距离；九种机型没有各自完整的攻击航线。机型之间的许多区别由伤害、射速、生命、射程倍率实现。见 [当前机型目录](D:/MyGame/EarthDefense/scripts/airframe_catalog.gd:5) 与 [当前交战移动](D:/MyGame/EarthDefense/scripts/battlefield.gd:969)。

当前 K3、M3、L2 已经具有锁定条件，M2 有范围预算，L3 能延后攻击，这些可以保留为基础。但锁定条件没有改变整架飞机的出击方式，保护它、打断它、让它从另一侧进入等选择也没有充分成立。敌军同样已有不同技能，却主要通过各类单位的波次比例混合出场，缺少有明确相互关系的攻击组合。见 [机型开火条件](D:/MyGame/EarthDefense/scripts/battlefield.gd:3342)、[敌军技能](D:/MyGame/EarthDefense/scripts/battlefield.gd:3241)、[波次组成](D:/MyGame/EarthDefense/scripts/defense_wave_plan.gd:4)。

因此，这次设计的验收不能再是“多了几个型号”。必须同时回答五个问题：它针对什么战场问题；它怎样飞和怎样完成一次攻击；它的弱点是什么；玩家如何为它创造机会；为什么模型必须长成这个样子。

## 战斗规则与玩家决策

### 保留的基础

地球、工厂、巡航、敌人来袭和弹道仍处于世界空间。同阵营飞机不增加实体碰撞；不恢复手动编队和屏幕航道标签。敌方普通飞机总体持续向地球前进，在具备对地攻击条件前攻击能合法交战的我机，到达对地射程后攻击地球。转向、绕行和蓄能不能重新变成反复掉头。

轻甲、重甲、能量层继续使用既有三家族克制。**动能对活跃能量层依旧为零**。能量层被打破后才按底层船体护甲结算。方向性盾板、外挂器官与完整能量层是不同机制，必须在模型和说明中区分，不能用“绕后”偷偷绕过全包覆能量甲。

导弹先于激光。常规科研保证基础反制可得，外星点承担分化和强机制；随机 Perk 不作为过关必需钥匙。科技树继续保留单属性小科技，不把新增行为再次捆成多属性礼包。

### 玩家实际决定什么

日常决定有四个：这一面缺追击能力还是范围火力；要不要为重武器让出编制；哪几座工厂承担防守、侧击或重击任务；永久投资要优先提高伤害、补造效率，还是攻防转化能力。

现有工厂背包增加机型的职责说明与编制配比即可。单机仍可覆盖设置，但默认按工厂模板生产。局部护航、夹击和火力分配由系统自动组织，不新增手动小队对象。选择“护航”意味着系统保留真实的护航名额与跟随位置，而不是给所有附近单位无条件挂光环。

工厂模板可提供守备、均衡、攻坚三个策略，分别建议保留约80%、50%、20%的本厂轻型编制承担近地任务，整数取整不能导致唯一一架拦截机也离开防线。此比例是初始可配置建议，不是新单位上限。未解锁对母舰攻坚时全部承担近地任务；解锁后也不会自动把全体飞机抽离地球。策略放在已有工厂配置中，不增加独立指挥面板。

强烈建议补一个**工厂内计划换装**：改变模板后，新造飞机按新模板生产；允许把现役飞机在完成当前攻击后自动返厂换装，支付公开的换装时间与原材料差额。队列串行执行，不靠自杀才能更新阵容，不让玩家逐架找飞机操作。局内换装不退还永久投资、不刷新冷却，不在交火中瞬间变形。此项需要单独实现，当前“下次补造生效”不足以让新解锁机型及时进入游玩。

### 所有机型共享的基本智能

正确瞄准、跳过零伤目标、避免对濒死敌人过量分配、最小目标保持时间、寻找地球不遮挡的攻击点、预测漏网单位、恢复后重新出击，均为基础能力。不能先故意让 AI 犯错，再出售修复它的科技。

机型状态至少包括接近、进入攻击姿态、执行攻击、退出危险区域、重新分配。只有需要稳定平台的重武器才减速准备；高机动拦截机不应跟着重炮一起悬停。

## 九种我方飞机

下列 K/M/L ID 只是沿用现有开发映射。名称、轮廓和具体参数仍可调整，但每张设计卡中的核心行为与弱点应保持清楚。

### K1 雨燕截击机：赶在漏网敌人之前到位

**战场职责。** 处理高速轻甲、绕过主火力的漏网机以及少量高危攻城弹。它是后期仍需要大量保留的基础机型。

**一次攻击。** 按敌人的预计到地时间选择拦截点，侧向切入，短促点射，掠过交会点后拉开，再选下一次交会。禁止一直追着敌机当前坐标跑；无法在地球受击前完成击杀时，可以选择更靠内的防线位置。普通进攻保持前向运动，只有残血且近敌满足原有条件时进入殉爆。

**建议原型节奏。** 一次开火约 0.8 秒，接着 1.2～1.8 秒转场；将六秒内的总弹量调到当前同级基准附近。高速度和转向优先，射程有限。基础点防由现有外星节点解锁，拦截敌弹占用自己的枪械开火预算。

**弱点与配合。** 重甲、全包覆能量层和正面盾板会消耗它的效率。它负责在激光破层后收割，也能优先清掉掩护攻城舰的轻型屏卫。

**专属演化方向。** “交会追击”在击毁当前拦截对象后缩短下一次转场；“末端拦截”优先把一次开火用于真正威胁地球的可拦截弹，不能变为全天候免费清弹。

**建模要求。** 小体积箭形机身、短翼、明确的侧向姿态喷口，双机炮位于机头两侧。短点射时枪口依次闪光，转场时侧喷口点亮。无需给基础机安装一排巨大主炮。

### K2 风暴扫荡机：沿敌群侧面扫出一个缺口

**战场职责。** 对付展开成宽面、密度较高的轻甲群。它创造覆盖，不能又得到最高的单体效率。

**一次攻击。** 选择一片正在进入防区的敌群，沿其侧面走一段弧线，两翼炮座顺序扫过约 40° 的扇区；扫射结束后退出半个射程冷却，再从另一侧进入。它围绕敌群的边缘行动，不跟随一个目标无限打转。

**建议原型节奏。** 约 1.4 秒扫射、1.6 秒冷却；开始攻击后保留本轮方向，允许小角度跟踪，避免每一颗子弹都自动转向新目标。基础是连续分次扫射。已有三发齐射科技仍是至多三发、两发副弹各为主弹 50%；不得把扫射次数与齐射再乘成九发并发。扇面命中与穿透遵守总伤害预算。

**弱点与配合。** 对单个小目标，许多射角没有收益；遭遇重甲单列或护层完整的舰群时收益低。M2 可以打密集重甲，L1 先开能量层，K2 再扫轻甲本体。

**专属演化方向。** “交叉扫射”把下一次进入方向改为相反侧，扩大实际覆盖；“收束炮座”牺牲扫角换单向有效射程，但不获得基础机的高追击速度。

**建模要求。** 宽而扁的飞翼，炮座分布在翼端并具有可见转动范围。左右大尺寸散热口在冷却时展开。轮廓宽度比雨燕更重要，不能只把雨燕同比放大。

### K3 猎隼穿插机：越过正面压力，拆掉关键支援

**战场职责。** 猎杀织幕、干扰和屏卫等低耐久关键单位，以及敌方大型机暴露的器官。

**一次攻击。** 自动选择左侧或右侧可达绕行点，先避开正面盾舟的保护角，再短暂稳定机头，打出高精度短爆发，沿外侧撤离。绕行是有距离和时间成本的，不能穿越地球或瞬移到敌后。

**建议原型节奏。** 0.8 秒稳定、两次间隔明显的点射、约 3 秒恢复；绕行路径最多三个控制点。优先权来自目标的支援作用，而不是给所有标注 support 的敌人一个无条件高倍伤害。

**弱点与配合。** 全包覆能量甲依然免疫动能；持续追逐逃逸目标、无支援的重甲海也不适合它。织幕机本体设计为轻甲、把防护投向队友，因此绕后猎杀成立；完整能量镜舰仍要先交给激光。

**专属演化方向。** “稳定记忆”允许转场后保留一部分稳定进度；“器官猎手”在可见弱点出现时优先射击该部件，代价是降低对普通目标的开火频率。

**建模要求。** 双梁或细长机身，中轴为长射击系统，侧推器明显，主翼较窄。进入稳定状态时两梁锁定、瞄准光短暂汇聚；开火与后坐要能看出来。

### M1 针蜂制导机：用有限弹仓分配确定的命中

**战场职责。** 处理正在移动的重甲与多个中等目标。与 K1 的即时补刀、M3 的一次重击区分。

**一次攻击。** 保持在拦截线后侧，获得最多三个有效目标锁，按预计剩余生命分配三枚待发导弹，再按短间隔释放。对同一目标已经有足够在途伤害时保留余弹或转给下一目标，避免三枚都打向快死的小机。

**建议原型节奏。** 弹仓上限三枚，每 0.9 秒补充一枚，至少一枚即可响应紧急重甲；最多同时维护三个锁。导弹有有限转向能力和寿命，不能掉头绕地球重新命中。发射筒有真实指向，不穿过自身机翼。

**弱点与配合。** 发射后的时间延迟、敌方屏卫和过量锁定都会损失效率。可用短间隔释放耗尽屏卫的拦截次数，为 M3 留出窗口；对普通轻甲仍不如相同编制的雨燕经济。

**专属演化方向。** “分布式锁定”增强分散目标响应，但限制单目标分配；“穿甲跟进”偏向已经破层的重甲，减少低价值锁定。库存和射速分开计量，不用隐藏加倍弹量制造强度。

**建模要求。** 三个可读弹仓或三组发射筒，状态灯对应准备好的导弹；机首为小型寻标器。轮廓像携带有限弹药的作战平台，不能与纯机炮战机只差一条贴图。

### M2 云爆轰击机：预判敌群将穿过的空间

**战场职责。** 打击密集重甲、运输队和被盾舟压缩成团的敌群。

**一次攻击。** 从较高的位置进入，预测敌群中心，在攻击航线上投出一枚非追踪爆破弹，随后立即拉开。爆破弹延迟约 0.5 秒展开，作用于一小片真实三维空间；敌人离开后不会继续追踪。

**建议原型节奏。** 一次攻击通场约 5～7 秒，爆破场持续 1.2 秒；最多处理六个目标，并限制总伤害。对同一大单位不重复按六个碎片结算。视觉可画多个火点，但结算使用有限次区域事件。

**弱点与配合。** 敌群散开、针翼快速突进、我军把敌人诱向另一侧，都会使轰击落空。它需要真实预测；精准爆破后的空域缺口是玩家应看到的收益。

**专属演化方向。** “长带布撒”将圆形爆区换成较长较窄的带状区，总预算不变；“延迟殉爆”牺牲即时伤害换更强的第二次爆破，不能让第二次爆破再次触发同一特性。

**建模要求。** 宽腹机身、显著的下挂爆破舱，舱门打开后弹体与机身分离。武器不是机头小炮；需要投弹、侧倾退出和舱门复位动画。

### M3 重槌鱼雷机：需要全队创造机会的对舰打击

**战场职责。** 打击攻城机、Boss 和母舰的关键结构。它的价值来自命中重击，而非整场不断输出。

**一次攻击。** 在外侧选择射界，减速、锁定、打开武器挂架，约 2 秒后发射一枚重型鱼雷。鱼雷在末段加速，具有有限耐久，可能被敌方屏卫拦截。发射后飞机转场重装，而不是继续悬停补小伤害。

**建议原型节奏。** 完整循环约 8 秒，最多一枚本机重型鱼雷在途；普通目标收益低，命中大型暴露结构时收益高。重击使可破坏部件受损或短暂失衡，不能把所有小机都炸出同样的高效率。

**弱点与配合。** 容易受到针翼猎杀、噬频干扰和屏卫拦截。K3 先拆屏卫，M1 耗掉其拦截次数，L3 保住鱼雷机的准备阶段，M3 才能稳定打出重击。

**专属演化方向。** “末段穿透”强化暴露结构伤害、降低爆区；“应急释放”遇袭时以不完整锁定发射，换生存但损失追踪能力。不给没有条件的全局巨额乘区。

**建模要求。** 鱼雷本身占机体可见体积很大一部分，采用腹挂长弹或分体夹持结构；机体有后坐补偿喷口。玩家应能看出它有没有装填，而不是只靠冷却数字。

### L1 辉光剥盾机：开一道让基础飞机发挥作用的口子

**战场职责。** 快速剥除有限能量层，并在破层后把目标交给擅长打本体的队友。

**一次攻击。** 从前线侧面接近，短时间保持稳定照射；当该目标能量层归零，若附近还有受能量保护的高威胁目标，就转向后者。附近没有需要剥盾的目标时继续攻击本体，不机械停火。

**建议原型节奏。** 1.0～1.4 秒照射、0.5 秒调焦；能移动，但转向受限。基础行为就具备破层后交接，而不是把正确分工锁进 Perk。

**弱点与配合。** 本体伤害和范围覆盖一般，遭遇无能量层轻甲海时不能替代 K1/K2。敌方护层被打碎后，基础机完成收割，是该机的核心反馈。

**专属演化方向。** “余辉转接”在破层后将一部分剩余照射时间带给下个目标；“剥离烙印”让刚破层目标短时间更易被动能击伤。收益次数受本机周期限制，不能无限连锁。

**建模要求。** 分叉的前置镜架，两个可转动的光学组件，细而连续的光束。破层时光束先收束再转移；不用长矛机那样巨大的固定主炮。

### L2 裂星波动机：选好射界后打出一段决定性的光束

**战场职责。** 攻击能量重舰、对齐的多目标和母舰，作为高风险持续光束平台。

**一次攻击。** 找到有价值的射线，进入稳定姿态，约 1.8 秒蓄能，再持续照射约 0.7 秒。照射期间只能有限转向，不能一帧内扫遍整个球面；随后折叠散热结构并换位冷却。

**建议原型节奏。** 总循环约 7 秒，最多穿过三个目标，后续命中递减且有总预算。需要同时检验蓄力前和发射时的射线；失去射界时允许保留短时蓄能，不能对地球背面硬开炮。

**弱点与配合。** 阵线被冲散、支援消失、针翼从侧面接近，都会让重炮准备付诸东流。射程长不代表可以在敌人绝对无法反击的位置免风险作战；继续遵守公平交战范围规则。

**专属演化方向。** “反相截断”把一次光束改为迎击一条已经预警的敌方光束，按有限能量预算对抗，牺牲正常输出；“穿列聚焦”加强直线穿透但进一步降低转向。此处借鉴 Burst 的攻防选择，不要求玩家做逐架精确按键。

**建模要求。** 长轴主炮或两个大尺寸镜臂，稳定时展开，散热鳍在准备结束前抬起，蓄能沿机体逐段推进。完成一次大幅可见的准备与释放，比增加细小炮管更重要。

### L3 回声护航机：让昂贵战机获得一次完整的出手机会

**战场职责。** 优先保护正在准备攻击的 M3/L2，其次保护返修中且有明确威胁的飞机。它不是低伤害但给整支舰队加倍率的光环单位。

**一次行动。** 领取最多两个护航对象之一的服务请求，移动到来袭方向，在局部展开约 90° 的定向屏障。屏障吸收有上限的实体弹、导弹伤害，随后冷却；不会自动挡住所有角度和所有光束。没有保护任务时才用弱光束协助破层。

**建议原型节奏。** 一次展开约 1.2 秒、冷却约 4.5 秒；吸收预算以同级我方耐久标尺计算，不能随敌方无限增长的伤害免费抬高。每个受保护单位同一时刻只接受一层这种护航保护，避免堆满支援获得无敌。

**弱点与配合。** 会占用两点进攻编制，只造它无法清敌。反方向攻击、光束和提前消耗护盾都会克制它。鱼雷机因此多打出一发重击，才是它有价值的证据。

**专属演化方向。** “回声反击”将实际吸收量的一部分转为下一次有限反击；“残骸回收”把一次成功救援后的恢复倾向调为受保护对象，但不增加新的可刷永久资源。反击仍按激光伤害类别结算。

**建模要求。** 明确的护盾弧面或半环结构，生成器朝向受威胁的一面，机体较宽。正常状态不画巨大透明罩；实际承受攻击时短暂显示屏障和充能槽位。

## 十种普通敌机：按造成的问题设计

首次出现时先用少量单一机制展示，再用混编放大。表中的波段是建议的教学安排，最终需要按真实科研收入和准备时间校准。

| ID / 敌机 | 造成的战场问题与实际行为 | 可行应对与失败代价 | 外观必须表达的功能 |

| E1 裂爪突击机，轻甲，开局 | 以小组前进并分批点射，构成基础火力压力；到达对地距离后转为对地攻击。 | K1/K2高效；堆慢速重炮会漏掉它们。是后期仍保留的轻甲基础目标。 | 短而尖的三叉头，开火器官在前端，动作简单直接。 |

| E6 棱镜镜舰，能量层+轻甲本体，约第13波 | 光学翼面锁定一个方向后，发射短时扫掠光束；扫描角和转速固定、有预警。 | L1先破层，K1收割；L2高级反相构筑可作有限对抗。不能靠普通点防消掉光束。 | 鳐形或三棱镜翼面，转动的镜片直接说明光束方向。 |

## Boss 与母舰的可见结构

**裂巢督军：选择先压本体还是先清释放出的压力。** 初见以轻甲为主，分阶段打开卵舱释放有限护卫；卵舱打开时核心短暂暴露。每批护卫占用事先保留的波次名额，击杀前可明确看到剩余舱数。基础机也能打赢，确保第一份永久奖励可达。模型是三瓣巢冠和少量大卵舱，不用先做十几个同时运转的机制。

**铸甲攻城侯：逼玩家做防弹与破甲取舍。** 正面盾板、巨型攻城弹、发射后的散热开口形成一个周期。M1可持续破甲，K1可牺牲部分对机输出拦下攻城弹，K3可在恢复期打器官。进入后续阶段再加入屏卫，使M3需要掩护。模型要有能合拢的盾板和真正打开的散热口。

**棱镜审判者：先拆攻击来源，再完成能量剥离。** 两到三个可破坏发射器承担不同方向的光束，破坏后对应攻击永久消失；本体能量层仍遵守常规规则。禁止长时间全身无敌与无预警全方向覆盖。发射器生命从总耐久预算中分配，不能把三个器官各塞一条完整Boss血量。

近地和外圈母舰继续承担来袭来源与阶段目标，不恢复远航玩法。本轮母舰只需加入有限的发射舱、护航组织或护层投射器官。三次外推分别增加“受保护的重炮”“交替出现的保护窗口”“混合任务压力”，不能只把生命、距离和敌机数量一起抬高。

## 波次应生成战术组合

继续使用固定周期与可配置总数量。组合模板只是把既定数量分配给角色和入场相位，不增加一套隐形护航刷新。若某一波预算不足，以主威胁和最小护卫组成缩小模板；Boss与资源小Boss名额优先保留。

| 十二个普通单位的示例组合 | 该局面要求的判断 | 不合适的应对 |
|---|---|---|
| 6裂爪 + 4针翼 + 2岩甲 | 保留内侧截击，少量破甲处理压阵单位 | 全部追着两艘重甲离开防线 |
| 2岩甲 + 1织幕 + 1蚀星 + 8裂爪 | 正面破甲，或穿插拆支援；同时处理攻城弹 | 只继续给动能加伤害，撞在外加能量层上 |
| 1蚀星 + 2屏卫 + 1噬频 + 8裂爪 | 先拆屏卫/干扰，或用短周期武器消耗其防御窗口 | 连续裸放昂贵鱼雷 |
| 3棱镜 + 1织幕 + 5裂爪 + 3针翼 | 剥盾后交接收割，并留出快机应对针翼 | 激光机永远打本体，或所有拦截机追同一目标 |
| 1孵化 + 2岩甲 + 3裂爪 + 舱内6幼机，总计12 | 选择提前重击运输舟，或准备范围清理投放区域 | 运输舟没死就不断无上限加怪 |

同组敌人保有松散的世界空间前后关系，并在较大的出生区域内展开。保护舰居前、支援舰居后、突击机从侧翼进入。无需画“XX航道”线；玩家看机体、前摇与掩护关系就应能判断。

一场典型局部遭遇可以这样发展：前排岩甲先吸引火力；织幕给它挂上外层；蚀星进入准备；雨燕留在内侧拦弹，猎隼沿外缘切向织幕；支援死亡后外层衰退，针蜂开始有效破甲；回声撑住重槌的准备，鱼雷命中攻城结构。这个过程里，每一种单位都改变了另一种单位的工作条件。

关键预警按**实际进入防区的时间**设计，不把“生成后两秒”当作所有距离的统一反应时间。远处来袭单位需要经过实际航渡，时间不够时不能先在屏幕外扣地球生命。固定波次继续推进，但首见高威胁机制必须留出建造或换装窗口。

## 解锁、科技与永久成长

建议首轮解锁顺序为：K1开局；约第3～4波可研究K2与M1；约第7～8波开放M2、K3；完成第10波可研究L1；约第15波开放L3；约第18～19波开放L2、M3。实际条件需要给足研究、建厂、出厂和飞抵时间，不能只保证节点在敌人出现的那一秒亮起。

不强制把九种机型全造齐。重甲可以由M1或M2主应对；支援可以由K3穿插、范围轰击或先正面剥盾再推进；远端大目标可以偏鱼雷或偏波动炮。普通常见能量甲不能通过随机稀有掉落才能获得反制。

前期永久升级优先保证伤害与补造能力，不能开局就把角色全部改成复杂机制。每种机型到中期再提供两条明确、有代价的演化方向，单机选择一条主方向，另一槽用于配套或稳定性。两条演化不应叠成毫无弱点的全能机。外星研究解锁行为，能源核心升级已取得的永久特性；不增加新币种。

工厂 Perk 的重点是改变出击组织。例如“轮班装配”让缺员补充更平滑；“集中校准”令重武器补造稍慢但出厂已经完成一部分准备；“快修平台”加强基础机的往返效率。它们各解决一个实际问题，不把产量、容量、攻击、护盾四种属性一起捆绑。

三种示例构筑按编制点而非飞机头数比较：

| 构筑 | 20点示例分配 | 体验与代价 |
|---|---|---|
| 高周转守备 | 10K1 + 2K2 + 4M1 + 2L1 | 常态拦截与清线强，依靠后期专属强化保住基础机用途；攻坚较慢。 |
| 穿插破阵 | 6K1 + 2K3 + 4M1 + 2L1 + 1L3 + 2点机动余量 | 通过拆支援和有限护航打开缺口；布局和路线质量比裸DPS重要。 |
| 重击防线 | 4K1 + 2M1 + 2L1 + 2M3 + 2L2 + 2L3 | 少量关键战机完成重击；快机比例较低，失去保护或被连续穿线时波动大。 |

构筑是用于原型比较的样例，不是保证最优的配方。不能把全部基础机换成高级机作为唯一正确方向。

## 外观与动画制作清单

首先制作机体灰盒、真实武器挂点和状态动画。先证明“扫荡机真的扫过敌群”“鱼雷机确实需要准备”“护航机确实站在正确的一侧”，再做表面装甲与 PBR 精修。

| 类别 | 第一轮必做的动画或结构变化 | 制作上避免 |
|---|---|---|
| 雨燕 | 短点射、侧推、掠过后的拉开 | 用长时间悬停假装截击 |
| 风暴 | 翼端炮座扫角、散热口展开 | 多画几根不参与攻击的小炮 |
| 猎隼 | 侧向插入、稳定锁定、两段射击 | 靠瞬移或无限转向实现侧击 |
| 针蜂 | 三格装填状态、发射筒指向、分次释放 | 发射方向与模型挂点不一致 |
| 云爆 | 弹舱开启、弹体分离、侧倾退出 | 把跟踪导弹换色称为轰炸 |
| 重槌 | 夹具打开、锁定、鱼雷脱离、重装 | 模型上有大弹体，实战只射普通小点 |
| 辉光 | 镜架调焦、持续照射、破层转接 | 无限数量同亮度光束盖满地球 |
| 裂星 | 稳定展开、逐段蓄能、释放、散热收拢 | 没有准备动作就瞬间激光扫屏 |
| 回声 | 转向保护侧、屏障受击、储能衰减 | 常驻巨大光罩与全队光环 |
| 敌军 | 盾板、投射器、卵舱、拦截器、炮口与实际功能一一对应 | 只靠颜色或微小天线区别职责 |

人类机型强调有限弹药、机械准备、光学对齐与维修；外星机型强调甲壳、器官、投射结构与孵化。外观参考只用于理解功能组织，不照搬现有游戏的具体船形。

在默认游戏距离检查轮廓，不以放大图好看作为唯一验收。关掉颜色和名字后，主要机型仍应可区分。发光负责表示蓄能、受击或能量层，不再让推进尾焰随武器状态闪白。

## 实施顺序与验收门槛

**第一步：完成一个足以推翻原有同质体验的灰盒遭遇。** 只做 K1预测交会、K3真实绕行、M3准备与重击，以及裂爪、岩甲盾舟、织幕、蚀星四类敌人。相同编制与科技下，加入正确角色应改变攻击顺序和战场结果。若灰盒仍主要靠堆面板过关，不继续扩模型。

**第二步：补齐覆盖与保护。** 加入 K2的扫射路径、M1弹仓分配、M2预测爆区、L1破层交接、L3有限护航，对抗盾舟与屏卫。先证明职责相互成立，再加入L2与棱镜对抗。

**第三步：接入教学波段、计划换装与永久演化。** 保留固定波次和总数量，按实际资源流测基础反制出现时间。换装、返修、补造不得复制飞机、退还已花永久币或刷新战斗冷却。

**第四步：美术精修与性能验收。** 根据已经冻结的弹道、射角、舱位和动画做精模。采用少量动作模板和有上限的局部协作；避免给每架飞机运行全场路径搜索，范围效果使用空间候选和明确伤害预算。沿用批处理，不新增每机灯光。

验收应包括以下可观察结果：

- 将单机伤害调到相近水平、隐藏名称，仅观察10秒行为，测试者能说明它在追击、扫荡、剥盾、护航还是准备重击。目标是首次教学后辨认率达到80%，这是待验证目标。
- 同资源和编制的对照中，正确搭配至少在两个相应遭遇中减少约25%的地球损失或明显缩短威胁持续时间；同时在另一种遭遇存在代价。不能只比较伤害排行榜。
- 中后期使用一定比例基础机的阵容，在穿线和屏卫遭遇中胜过纯高级机阵容；否则基础机的长期作用仍未成立。
- 统计漏网数、攻城弹拦截、护层击破后的交接时间、重击完成率、护航期间实际防止的损失。悬停工厂或波次摘要可查看，不新增满屏常驻标签。
- 保存/读取保留弹仓、锁定、任务与冷却，不重复领取部件或幼机奖励。殉爆不会绕过伤害家族的能量免疫。
- 同场景对比总CPU耗时、分配频率、投射物与范围结算数量。现有全科技400单位压力测试仍有CPU负担，不能靠增加每帧全表扫描落地这些机制，也不能把方案写成已达到300FPS。
