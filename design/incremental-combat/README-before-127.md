# EARTHWARD · 地球守望 1.26 C# 开发版

Godot 4.6.1 .NET / C# 三维地球防御增量游戏。工厂建在球面六边形上，生产战机保卫地球；敌军从固定母舰方位进攻。当前开发重点是地球防御、装甲克制、独立科技和跨局永久特性，远航玩法保持关闭。

## 1.26 局部防御与单次研究

- 飞机基础巡逻半径及外出追击距离默认扩大到2倍。参数页「基础战斗」增加巡逻覆盖倍率 `patrol_coverage_multiplier`，默认2，可调0.25–8；已有飞机与科技/特性实时联动，旧档缺参数使用新默认值。
- 点击飞机工厂显示巡逻/追击的地表投影、空域上下边界与高度线，并弹出紧凑数值卡。小卡显示巡逻半径、巡航高度区间、武器射程与最高可攻击高度；没有在役战机时展示待生产配置。只显示选中的工厂，边界随地球自转，空地/右键/Esc/建造/切换天体会收起。
- 普通敌机、小Boss及三类Boss抵达近地合法位置后停止球面移动、朝地球轰炸。保留原有技能和轰炸窗口，随后撤离；行进途中继续执行原对机攻击逻辑。
- 导弹新增「双联挂架」中科技（每轮+1枚），以及爆炸半径+15%、制导射程+15%、飞行速度+20%三个科研小节点。
- 全部173个静态科技均只有一级；原重复精研转换为独立后继节点，每枝保留最多10000阶的增长。旧档已购等级自动转入，不重复叠加。画布提供后继历史窗口与「最新」导航，避免同时实例化数万个节点。
- 小、中、大及后继节点统一单击研究；效果、费用与前置保留在悬停提示中。二次确认面板及代码已经删除，已完成节点再次点击不扣费。
- 敌母舰进入新阵地前最后一个波周期显示顶部预警，包含下一层、距离和倒计时。首次沿用5波休整；第二、第三次外移留出1个当前配置波周期的转移窗口；第三层的同阵地增援不会误报外移。
- 参数面板新增「资源作弊」页，可输入正增量添加矿物、能源、科研、资源核心、外星科技点和永久能源核心；另有「解锁全部科技」按钮，只完成常规科技树，不购买进阶后继节点，已有进阶等级保留。普通资源与科技使用存档事务，保存失败回滚；永久核心使用原永久档案的原子写入。
- 体积云底部抬到离地0.20、云顶0.48，高云0.52；大气层外缘离地1.00。保持原采样档位与地球/相机尺寸，云形态仍用既有体积密度图。
- 体积云消光 `volume_extinction` 由 24 降到 14（着色器默认值、`earth_surface.gd` 与 C# `EarthVisual` 运行时参数同步下调），云层更通透；运行时覆盖是必需的，因为导出场景 `earth.scn` 已烘焙旧值。
- 能量盾改为局部护盾发生器：先研究D_S01，再花24科研解锁D_N4；首座需120矿物、100能源，初始无塔。护罩位于大气之外、离地1.28，地表弧覆盖半径5；每塔初始容量100、每秒恢复0.8，已有护盾科技作用于每座设施。范围外攻击直接伤及地球；护罩有受击闪光和破盾表现，多个重叠护罩不会重复扣同一笔伤害。

旧档的资源、科技、永久特性、工厂归属和机群UID保持。旧全球护盾余额仅保留为兼容存档字段，不再暗中提供全球保护；旧交战存档首次载入会暂停，便于研究并放置护盾后按空格继续。原通关备份不被开发测试改写。

## 1.25 地图更新

地球实际半径由1.24的8扩大到16，直径再扩大一倍，地表面积再增至四倍；建设网格由10242格增加至40962格，建筑和飞机的世界尺寸保持。开局即可自由缩放、旋转、查看全球与星域，飞机观战也按原操作开放。没有按波次解锁视野、限定相机高度或锁定防区的规则。

云层高度、地形高差、飞机离地高度与武器局部射程保留。三层敌母舰半径56/88/128、科技行动半径62/96/140维持原来的离地距离。旧R4、R8存档按来源只适配一次，永久特性、工厂归属与机群UID保留。

详情见 [1.25 地图更新与验收](artifacts/earth125-results.md)，前版友方子弹模型修复保留。

## 启动当前源码

- **`LaunchNewCampaign.bat`**：体验 C# 版本的完整成长曲线和当前巡逻数值。使用 `.runtime/new-campaign` 独立进度，第一次新开局，后续继续该进度；重新开始可在游戏内操作，永久特性仍保留。
- **`LaunchDebug.bat`**：延续原通关备份所建立的开发进度，使用 `.runtime/debug-cleared`，不会每次重置。
- 两者均先编译最新 C# 源码，再由 Godot .NET 导入资源、启动游戏；编译失败会停止，避免误玩旧程序集。优先采用 `GODOT_DOTNET_EXE`，默认使用本机 `D:/MyGame/Godot/4.6.1-net/Godot_v4.6.1-stable_mono_win64_console.exe`。日志在对应运行目录。
- **`Launch.cmd`** 也已接到 `LaunchDebug.bat`，启动当前 C# 开发版。`builds/` 中既有的旧发行包仍保留原样。
- 工程需由 **Godot 4.6.1 .NET** 打开。原标准版 Godot 编辑器不能运行 C# 入口。SDK 由 `global.json` 固定为本机 .NET 10.0.100，游戏目标框架为 .NET 8。

原第 125 波通关备份保留在 `saves/backups/20260910-003354-827-pre-expedition-design`。本次迁移前的完整源码、启动器和两套开发进度备份位于 `saves/backups/20260910-194917-pre-csharp-migration122`。测试统一使用 `.runtime-tests` 隔离目录。

## 当前玩法

科技树改为 **173 个独立节点**，包含动能、导弹、激光、工业、防御、指挥六枝。123 个小科技只花科研；20 个常规中科技、18 个外星中科技、12 个大科技分别承担新机型、机制分化与阶段突破。所有节点单击研究，悬停查看本节点效果、真实费用和前置。六个终局节点各自接出独立后继链，所有后继也只能研究一次。

每个节点只提升一种属性，或承载至多两项关联效果。小科技通过不同图形标示伤害、射速、弹速、射程、产量等属性；不再点击一组后暗中购买一堆升级。完整画布可左键拖拽和滚轮缩放，右栏有卷轴展开动画，保持游戏相机与画幅不变。

| 舰体护甲 | 动能伤害倍率 | 导弹伤害倍率 | 激光伤害倍率 |
|---|---:|---:|---:|
| 轻甲 | 1.60 | 0.65 | 0.65 |
| 重甲 | 0.20 | 1.65 | 0.65 |
| 活跃能量甲 | 0 | 0.20 | 1.80 |

能量层耗尽后改用底层船体护甲结算；该表为基础倍率，科技、机型和特性随后参与结算。导弹先于激光解锁，激光需完成第 10 波。鼠标悬停单个敌人可查看当前护甲、能量层和克制信息，不显示满屏小飞机血条。

| 家族 | 基础机型（1 编制点） | 特化机型（各 2 编制点） |
|---|---|---|
| 动能 | 雨燕拦截机 | 扫荡机、猎隼机 |
| 导弹 | 破甲导弹机 | 震荡轰击机、破城鱼雷机 |
| 激光 | 辉光激光机 | 灼盾长矛机、光脉冲压制机 |

特化机型分别承担多目标扫荡、支援猎杀、范围轰击、对舰鱼雷、持续破盾和干扰压制。基础机型以低编制占用、补造效率和各自合法特性保持用途。通过现有特性背包配置工厂及编制机型；切换在**下次补造**时生效，空余编制需容纳新机型，不会瞬间改变在场飞机。工厂和战机各自装备 Perk，永久等级用能源核心升级并保留到下一局；旧特性、已付等级和余额保留。

敌军有 8 种战斗角色：裂爪、针翼、岩甲、蚀星、棱镜、织幕、孵化、噬频；中 Boss 逐步引入裂巢督军、铸甲督军、棱镜审判者。新机型与敌军都使用独立 PBR 几何外观与批量渲染。

每波默认 **45 秒固定周期，前 30 秒刷出本波计划数量**；残余敌人不拖长本波。参数中可编辑周期、刷新窗口、数量倍率和生命/伤害增长。下一波护甲构成显示在紧凑 HUD 提示中。第 3 波起已有中 Boss 永久奖励，外星点贯穿成长过程；资源小 Boss 仍每波提供可配置资源核心。

初次母舰攻坚需完成第 24 波，保证轻甲、重甲、能量甲和混编防御都进入实际流程。八艘近地母舰首次清空后，默认休整 5 个波周期，新档为 **225 秒**。随后继续地球防御，母舰按三个阶段拉远到地心距离 **56 / 88 / 128**，对应行动半径科技逐步突破。旧档已保存的显式参数保留，休整按该档实际周期计算。

## 工程与验证

入口为 `project.godot` / `main.tscn` → `src/Application/Main.cs`；解决方案为 `Earthward.sln`，工程为 `Earthward.csproj`。游戏运行时不加载或调用 GDScript。着色器继续使用 Godot 原生 shader。

| 目录 | 职责 |
|---|---|
| `src/Domain` | 资源、科技、机型、Perk、工程参数、数值编译与兼容存档 |
| `src/Combat` | 纯托管战斗、巡航、索敌、弹道、伤害、生产维修、波次与母舰阶段 |
| `src/Rendering` | 地球、体积云、天体、球面建筑、MultiMesh 舰队与特效 |
| `src/Presentation` | 研究画布、特性背包、HUD、参数界面、观战、音效 |
| `src/Application` | 主循环、输入路由、界面组合、存档事务 |
| `data/domain` | 科技、机型、Perk、经济与历史兼容 JSON 目录 |
| `assets/managed` | 从原版模型烘焙的无脚本场景与网格，保留 PBR 材质和动画部件 |

`scripts/` 保留为 1.22 对照参考，不参与当前入口或导出。修改玩法请编辑 C# 与 JSON。原版对照数据已导出，日常 C# 回归无需调用旧脚本。

```powershell
# 编译 C# 并检查原生资源导入
powershell -NoProfile -ExecutionPolicy Bypass -File Build.ps1

# 完整数值、战斗、原生渲染、旧存档及真实鼠标交互回归
powershell -NoProfile -ExecutionPolicy Bypass -File tools/test_managed.ps1

# 无显示设备时，跳过真实原生鼠标交互测试
powershell -NoProfile -ExecutionPolicy Bypass -File tools/test_managed.ps1 -HeadlessOnly
```

Debug 构建开启 C# 优化并保留 PDB。`Build.ps1 -Export` 提供桌面发布入口，需要安装匹配的 **4.6.1 .NET Windows 导出模板**；本次验证的是源码运行版，没有用旧发行包冒充新的 C# 发布包。

保留 MultiMesh、共享 PBR 材质与空间检索；新模型在加载阶段预烘焙，能量甲和蓄能提示通过实例数据传给 GPU。没有给每架飞机增加灯光、同阵营物理碰撞或常驻血条。

C# 迁移、存档兼容、性能测量和验证边界见 [1.23 迁移报告](artifacts/csharp-migration-results.md)。此前玩法验收见 [1.22 交付报告](artifacts/deep-combat122-results.md)。完整设计位于 [综合设计](design/incremental-combat/combined-design-v1.md) 与 [科技目录](design/incremental-combat/technology-catalog-proposal.md)。此前版本的 README 保存为 [历史开发说明](design/incremental-combat/README-before-122.md)，其中旧远航、旧科技组与旧波次规则不代表当前玩法。
