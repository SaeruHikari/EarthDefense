# Procedural celestial background

`deep_sky.png` is an original, deterministic, artistically composed sky panorama generated by `tools/generate_deep_sky.py`. It does not incorporate external photographs, survey data, or third-party artwork. It is a stylized fictional celestial sky, not an astronomical catalog.

The 4096 × 2048 equirectangular cache contains a layered galactic band, dark dust lanes, cool cyan and muted violet emission, small warm dust regions, and 27,000 stars of different apparent intensities. Broad noise, star cores, and the soft halos around selected bright stars are baked once. The deterministic seed is 108273.

The game loads the mipmapped panorama into one `ColorRect` shader. Each pixel samples the panorama using the actual perspective camera's world-space direction, so orbiting the camera changes the visible celestial sky. A gentle composition mask keeps the center and outer screen edges quiet without attaching any star to a screen coordinate. Only a very small shader-driven brightness variation affects bright stars; there is no per-frame CPU star loop or multi-octave procedural noise.

Regenerate from the project root with Python, NumPy, and Pillow:

```text
python tools/generate_deep_sky.py
```

The PNG is display-referred and intentionally restrained. It supplies the 2D deep-space background; HDR emission and Bloom for the 3D planet, atmosphere, and combat effects remain in the separate world viewport.
