# Cloud top relief data

`cloud_relief.png` is generated by `tools/bake_cloud_relief.py` using NumPy and Pillow. This new asset supersedes the old main texture only when explicitly selected by the runtime. The original main, cirrus and wind textures are left untouched by the generator.

The 4096 x 2048 RGBA texture contains **linear numerical data**:

- **R**: Cloud coverage. Derived directly from the source map at 4K with `smoothstep(0.14, 0.76, source)`. No coverage blur or broad veil is added.
- **G**: Signed eastward derivative of the normalized radial cloud-top height, encoded with 0.5 neutral.
- **B**: Signed southward derivative of normalized cloud-top height, encoded with 0.5 neutral.
- **A**: Normalized radial cloud-top height. This is actual height data, not optical thickness or preview opacity.

Cloud-top height is formed from broad overlapping Gaussian cloud turrets at approximately 1-3% UV scale, an additional pair of rounded turret populations with 10-40 pixel radii, broader smooth variation, and small 0.2-0.6% detail. The broad height contrast is expanded about its midpoint and smoothly bounded with tanh; this preserves valleys without producing saturated plateaux. The continuous additive Gaussian union avoids sharp cellular Voronoi ridges. The source coverage controls the cloud footprint, while cloud-top variation remains independent inside saturated white regions. Only the height envelope is softened over eight pixels to avoid needle-like geometry; coverage remains sharp.

Runtime displacement:

```
radius = cloud_base_radius + cloud_height_range * texture.a
```

For base radius 4.08 and range 0.20, this bake reaches radius approximately 4.263. The height range controls an upper limit, rather than forcing every asset to contain a height of 1.0.

Normal reconstruction:

```
gradient = texture.gb * 2.0 - 1.0
strength = cloud_height_range / cloud_base_radius * 16.0
normal = normalize(radial - east_tangent * gradient.x * strength
                          - south_tangent * gradient.y * strength)
```

At the above scale, strength is **0.7843137255**. G already includes the spherical longitude metric `1 / sin(pi*v)`; do not apply a second latitude compensation in the shader. G/B store the derivative, not the negated normal. Derivatives are softly limited by the finite stored range, with 9.43% of channel values clipped at abrupt visible cloud edges before packing. 8-bit neutral is 128/255, as with the existing packed cloud assets.

Longitude is periodic. The narrow caps at v < 0.0015 and v > 0.9985 collapse to a longitude-independent state, transitioning back by 0.005 and 0.995. Gradients fade close to the coordinate singularity.

Import uses high-quality VRAM BC7/BPTC compression and full mipmaps. Sample without `source_color`. Do not enable normal-map auto-detection, alpha-border repair, alpha premultiplication, gamma conversion or channel swizzles. Godot must import the new resource before a build references it.

`CLOUD_RELIEF_STATS.json` records the seed, hash, geometry normalization and seam checks. `artifacts/cloud-relief-bake-preview.jpg` is an offline flat-map lighting check, not a game screenshot. Final normal orientation, compression, displaced silhouette, shadow agreement and GPU cost require runtime verification by the integrator.
