# EARTHWARD · 地球守望 1.27 C# 开发版

Godot 4.6.1 .NET / C# 三维地球防御增量游戏。玩家在地球六边形表面建设采集与防御设施，配置九种战机，利用兵种克制和长期科技成长抵御敌舰。当前玩法集中在地球防御；远航系统保持关闭，持续科研由玩家通过卫星发射中心送入轨道的科研卫星提供。

## 启动当前开发版

- **`LaunchNewCampaign.bat`**：使用 `.runtime/new-campaign` 独立进度体验完整成长曲线。第一次新开局，之后继续该进度；游戏内可以重新开始，永久特性保留。
- **`LaunchDebug.bat`**：继续 `.runtime/debug-cleared` 的开发进度；检测到旧架构存档时会清理该开发 profile 并从新局开始。
- **`Launch.cmd`**：转到 `LaunchDebug.bat`。

两个入口都会先发布当前 C#、导入当前资源，再启动**官方 .NET Release player**。游戏从当前项目目录直接读取场景、模型、着色器和 CSV，不使用 `builds/` 中的旧包，也没有额外制作一份资源 PCK。

运行器是项目根目录的 `EarthwardPlayer.exe`，标准自包含 .NET 输出在 `data_Earthward_windows_x86_64/`。它们都是可重新生成、已被 Git 忽略的文件。下载来源和 SHA256 记录在 `.runtime/managed-player/SOURCE.json`；最近的发布配置、程序集位置和散列在同目录 `PUBLISH.json`。

首次启动会从官方 Godot 4.6.1 .NET 模板包中下载并校验 Windows x64 player，并恢复所需的 .NET 发布依赖。Godot 编辑器安装不被修改：编辑器负责资源导入，实际游玩使用 `ExportRelease` 的游戏程序集与 GodotSharp Release API。资源与代码准备失败时，启动器停止并保留日志。

需要 **Godot 4.6.1 .NET** 和 .NET SDK；`global.json` 固定 SDK 基线为 10.0.100，游戏目标框架是 .NET 8。编辑器路径优先取 `GODOT_DOTNET_EXE`，本机默认是 `D:/MyGame/Godot/4.6.1-net/Godot_v4.6.1-stable_mono_win64_console.exe`。正式 player 使用同目录项目，启动时不要给它传 `--path` 或位置式场景参数。

历史通关备份仍位于 `saves/backups/20260910-003354-827-pre-expedition-design`，仅供回看旧版本。开发存档与测试统一写 `.runtime` / `.runtime-tests`；当前开发版不读取旧架构存档，改动数值或结构后请从新局开始。

## 1.27 科技成长

科技树由 **248 个独立、单级的常规节点**组成：195 个小节点、23 个常规中节点、18 个外星中节点和 12 个大节点，分为动能、导弹、激光、工业、防御和航程指挥六枝。

- 小科技只消耗科研，连续属性升级拆成可以频繁购买的单个节点。中科技承担机型解锁或机制分化，大科技提供阶段突破。
- 所有大小的节点均单击研究。悬停显示实际效果、费用和前置；没有二次确认详情页，已购节点重复点击不再花费资源。
- 画布按真实依赖分成 **13 圈**。单前置升级位于上一节点的下一圈；多前置节点位于最深前置的下一圈。97 对连续小科技沿同一条径向线相邻排列；局部修复也紧邻其护盾工程前置。
- 较早或跨枝前置保留为较淡的虚线，悬停/选中时高亮。清理重复分支后，全部 287 条有效依赖均有连线。
- 六个终局节点各接一条最多 10000 阶的独立后继链。每阶仍只能购买一次；画布只加载当前历史窗口，支持前后翻页与返回「最新」，不会创建六万个 UI 节点。
- 左键拖动画布、滚轮缩放。右侧栏展开保留卷轴动画，游戏内相机位置、参数和画幅不因科技栏变化而跳动。

已删除同属性低收益的「弹芯精炼」「光束稳定」「光程校准」「产线协调」「远端调度」「巡航扩界」六条平行链。导弹同阶段重复分叉保留较强的「扩散爆轰」「持续助推」，后续升级接回这两条路线。共移除 52 个小节点，保留节点的收益、费用和解锁条件保持原值。

容量研究现在只有三项中科技，每项增加 1 个编制点，研究合计最多 +3，前置改接保留的装配节拍链。工厂本身的容量基数、工程倍率和永久特性独立生效。

科研入口已经从地面研究所收敛到科研卫星。**卫星发射中心是建设栏的第一项，开局免费、限建一座，占中央格及相邻六格组成的七格蜂窝。** 实际模型也覆盖这七格：中央是加高的发射塔和发射台，外围六格铺设贴地平台、储罐、供电与遥测设施。开局引导提示先建中心；建成后点击地表中心，在悬浮卡片中免费发射第一颗科研卫星。

发射使用 PBR 火箭模型，依次演示上升、级段分离、整流罩分离和卫星入轨。**初始科研为 0**，完成入轨后卫星开始提供科研；默认科研基数为 0.8，乘当前资源产量系数 0.1 后为 **0.08 科研/秒，即 4.8/分钟**。击杀及波次结算不再赠送科研，矿物、能量、资源核心、外星科技点与芯片规则保留。初级常规小科技售价 4～6，对应约 50～75 秒一次研究；科研升级与后续退款科技继续提供成长。

为匹配新的科研收入，保留科技效果、前置和外星点门槛，压平科研费用断层：导弹解锁 **8**、激光解锁 **16**；二层小点原 18～27 降为约 6～9，三/四层继续递增。常规中科技原 80/260 级别调整为 18/33，工业计算阵列由 300 改为 49。可选的「局部修复」仍为 24，免费区域护盾工程仍为 0。研究科研方法后，一条包含导弹、激光与基础属性的 15 次研究路线约需卫星上线后 15.1 分钟；中大节点需要单独积攒，不承诺每一个节点都恰好一分钟。

六条进阶链的首级科研费用也从 1200 调整为 **70**，第二级为 **86**，保留原 ×1.22 科研费用成长与外星科技点门槛，避免主树点完后一次 +3% 的研究需要空等一小时。

科研卫星的世界空间轨道按发射中心位置确定，经过发射台正上方，保证火箭可以直接抵达。当前轨道地心半径为 **20.25**，相对半径 16 的地球高度为 **4.25**；轨道在发射中心建成后才显示，开局和重开时隐藏；可见轨道环位于大气层外，由半透明主环与光晕提示。卫星沿轨道运行，自身不占地表格；点击已入轨的科研卫星直接打开科技侧栏，不额外暂停或移动镜头。当前仅开放这一颗科研卫星。

## 巡航、防区与母舰攻坚

战机工厂的基础造价进一步下调：拦截机工厂 **70 矿物 / 30 能量**，导弹机工厂 **180 / 100**，激光机工厂 **360 / 270**。实际建造价继续按已有同类数量递增；开局已有 1 座拦截机工厂，因此下一座显示为 **91 矿物 / 39 能量**。

本轮把正式表中的基础巡航半径和远端范围各提高 **50%**，对应的 32 个科技增量也提高 **50%**。原有 `patrol_coverage_multiplier` 参数保持默认 2、范围 0.25–8。已经购买的研究重新载入后自动使用新表值，所有权和等级不变。

| 工厂家族 | 表内巡航半径 / 远端基数 | 默认参数下开局巡航半径 / 远端范围 | 首清前可达研究完成后的覆盖半角 |
|---|---:|---:|---:|
| 动能 | 1.875 / 1.125 | 3.75 / 2.25 | 28.6° |
| 激光 | 2.4 / 1.35 | 4.8 / 2.7 | 35.7° |
| 导弹 | 2.85 / 1.5 | 5.7 / 3.0 | 41.4° |

上述表格使用默认参数、基础机型和未装备额外范围特性的配置。巡航半径与远端范围是球面弧长；追击半径是地心距离，不能与武器局部射程混为一谈。

点击飞机工厂即可显示实际能力覆盖：薄荷色巡逻边界、琥珀色追击边界，以及淡蓝色空域高度线。悬浮小卡显示巡航半径、巡航高度区间、武器射程和最高可攻击高度。混合配置显示最小–最大值；无在役飞机时展示生产计划预览。范围计算直接来自战斗系统，地表环只是其投影，实际命中仍受高度、射程、瞄准、遮挡和护甲影响。

「母舰攻坚」仍在第一阶段正常解锁，需完成第 24 波。初次近地母舰位于地心半径 21.65，攻坚行动半径为 24；不要求先击败母舰才能购买其前置。**动能无法穿透能量层；应先用激光破盾，再由动能接力。** 导弹可以攻击能量层，但伤害效率较低。

八艘近地母舰首次清空后，默认休整 5 个波周期。随后敌母舰依次外推到地心半径 **56 / 88 / 128**；相应科技将行动半径推进到 **62 / 96 / 140**，前一级仍不能跨过下一层航程门槛。每次真正外移前的最后一个波周期显示顶部预警；同阵地的重复增援不误报外移。

每艘新出现的敌方母舰单独触发一张「检测到高能信号」卡片，显示 **8 秒**后淡出。多艘同时到达时按顺序逐张提示，新增母舰不延长当前卡片的寿命；卡片没有总数量、分页编号或手动切换按钮。巨型感叹号与世界方向箭头保留，点击定位当前这艘母舰；已撤离或被击毁的待提示目标自动跳过，存活旧母舰不反复提示。换阵地的提前预警也只显示一张定时方向卡。参数、成就等遮挡面板打开时暂缓提示计时，普通暂停仍可查看并让提示正常消失。

## 兵种与防御

| 目标当前护甲层 | 动能 | 导弹 | 激光 |
|---|---:|---:|---:|
| 轻甲 | 1.60 | 0.65 | 0.65 |
| 重甲 | 0.20 | 1.65 | 0.65 |
| 活跃能量层 | 0 | 0.20 | 1.80 |

能量层耗尽后使用底层船体护甲结算。表中是基础相性，随后再应用机型、研究与特性。激光需取得第 10 波情报；高级机型继续按自身研究及阶段门槛解锁，并非第一阶段全部开放。

| 家族 | 基础机型：1 编制点 | 特化机型：各 2 编制点 |
|---|---|---|
| 动能 | 雨燕拦截机 | 扫荡机、猎隼机 |
| 导弹 | 破甲导弹机 | 震荡轰击机、破城鱼雷机 |
| 激光 | 辉光激光机 | 灼盾长矛机、光脉冲压制机 |

基础机以编制效率、补造速度和相应特性保持用途。机型在现有特性背包中排产，改型在下次补造时生效，在役飞机不瞬间改变。每种工厂和战机都有独立的双特性槽；39 种特性通过背包图标、拖放和局部详情配置。特性改为使用**外星芯片购买与永久升级**，具体编制配置会被该位置的阵亡补造继承。

击落普通敌方战机（scout/cruiser）默认有 **3%** 概率掉落 **1 枚外星芯片**，Boss、母舰和资源运输单位不掉芯片，也不再直接赠送特性。普通特性购买 3 枚，高级特性购买 10 枚；高级特性仍需首次清空 8 艘近地母舰后开放。普通升级费用为 `ceil(2 × 1.35^(当前等级−1))`，高级为 `ceil(5 × 1.5^(当前等级−1))`。背包选择未拥有项时显示 Lv.1 效果与购买价，买入后可免费拖到适用槽位；已拥有项显示升级价与下一等级收益。伤害、射速、护甲、航程等主要增益和成长降低约一半；扩展机库由每级 +1 改为 L1 +1、之后每 5 级再增加 1 个编制，L25 总计 +5。

芯片、已购特性和等级独立保存到 `user://earthward_alien_chip_perks.json`，重新部署与重试本波不回滚。旧货币档不作迁移；新系统使用独立档案，现有局内研究与成就不受其影响。掉落以本局和敌机波次身份稳定判定，回档不会重掷概率或重复领取。战斗每秒批量保存芯片，保存、战败、退出及重开前结算；仅余额变化不触发机群属性重算。掉率读取 `perk_economy.csv`，购买和升级曲线读取 `perk_tiers.csv` / `perks_settings.csv`，实际效果读取 `perk_effect_rules.csv`。

工厂负责生产、维修与补造，损伤严重的飞机在附近有合适敌人时可以冲向目标殉爆。无同阵营物理碰撞；小飞机没有常驻血条，残血通过闪红反馈。敌军保留八种角色和三类 Boss，使用独立外星 PBR 轮廓、能量层和技能提示。

局部护盾发生器由科技树中的「区域护盾工程」直接解锁：这是一个一级中科技，科研消耗为 0，首次地球实际受伤时自动暂停战斗，将受击点聚焦到科技侧栏左侧的可见画面，并展开科技树、居中定位「区域护盾工程」。节点显示持续可见的红色脉冲环；镜头采用约 1.4 秒的球外绕行与缓入缓出，业务暂停期间镜头过渡与 UI 动画继续播放；玩家拖动或缩放可从当前画面接管镜头。研究后清除高亮并保持暂停，玩家可布置护盾后按空格继续；同一局后续受击不会反复抢走镜头。发生器建造不消耗矿物、能量、科研或资源核心，但每次建造后有 3 波冷却；场上数量由防御科技上限控制，并随 D_N1/D_N2/D_N3/D_G1/D_G2 提升。它保护覆盖范围内的地球表面，范围外攻击由地球承受；已有护盾科技作用于每座设施，重叠护罩不会重复扣同一笔伤害。新增小科技「局部修复」后，每座发生器以 0.02 点/秒的极慢速率修复地球耐久，实际速率会显示在护盾卡片和顶栏。原「修复防线」手动指令已移除，战斗恢复只由护盾自身恢复、局部修复科技与战斗内机制负责。资源设施建设消耗资源核心，还可以通过顶栏核心强化工具注入核心，提高单座设施产能。

地球半径为 16，建设网格为 40962 格；建筑和战机尺寸独立于星球半径。开局即可自由旋转、缩放和查看星域，没有按波次解锁视野的限制。地球、分层体积云、大气和共享 PBR 场景继续由 C# 与原生 shader 渲染。

局部护盾发生器的基础护盾强度为 **200**，基础恢复速度为 **1.6/秒**，两项均为先前的两倍。现有科技百分比继续作用于新基数；建筑卡片和顶栏同步显示实际值。

## 波次、存档与参数

每波默认 **60 秒**固定周期，前 **45 秒**分批部署。敌军数量基数为 **6**、每波增加 **1**、数量倍率为 **2**；未击毁母舰且不调整参数时，第 1/3/5/10/15 波总数为 **9/16/20/30/40**，已包含该波 Boss 配额。数量倍率改变本周期内派出的数量，不延长周期；周期、部署窗口、数量增长和战斗参数仍可编辑。第一波保留独立数量、生命和伤害倍率（分别 0.75、0.85、0.75）。敌机基础 DPS 从 19.5 降为 **11.7**，对地最低单发伤害从 1.5 降为 **0.75**；精英延至第 **5 波**、精英伤害倍率由 2 降为 **1.5**。敌方齐射每 **180 秒**增加一发，中 Boss 仍提供外星科技点，资源小 Boss 按配置掉落资源核心。

在上述基础上，前 **10 波**敌方伤害及对地最低伤害再乘 **0.35**，为新母舰方向已打到地球、玩家才转向补防的情况留下反应时间。第 **11～20 波**每波将该倍率增加 0.065，至第 20 波恢复为 1，避免前期保护突然撤掉；普通敌机前 10 波伤害为本轮修改前的约 21%。三个参数均在 `combat_tuning.csv`：`OpeningDamageMultiplier`、`OpeningDamageHoldThroughWave`、`OpeningDamageFullWave`。

战斗参数与局内记录携带数值版本。首次读取旧参数时，只更新本轮调整的数量基数、数量增长、波周期、部署窗口、弹幕成长间隔，其他工程配置保持；本版本之后手动编辑的值正常保存。正在进行的旧波次保留已锁定的计划，下一波使用新参数；体验零科研开局应重新部署一局。

战败后的「重试本波」使用独立波首检查点，从部署计时和已刷数量为零的开头恢复，并暂停供玩家整备。普通「继续上次防御」仍加载准确的中途断点。波首记录由当前版本写入并用于重试本波；永久特性档案不回滚，同一永久奖励不重复领取。

右上角参数按钮左侧的勋章入口打开成就列表。当前只有一个成就「不灭的守望」：首次地球防线失守时自动达成，独立保存到 `user://earthward_achievements.json`，重新部署、重试本波和重启游戏均保留，无需领取或装备。达成后，每项增加局部护盾建造上限的科技额外增加 **1 座**：首次区域护盾工程提供 2 个基础配额，有成就时为 2 + 1 = 3 座；后续基础增加 2 座的大科技实际增加 3 座，全部六项容量科技由总计 9 座提升到 15 座。未研究时仍不可建造，三波建造冷却保持不变。成就规则与加成读取 `data/domain/achievements.csv`，科技悬停说明显示实际增量。查看成就时暂停模拟，关闭后恢复原来的暂停状态；战败时关闭则返回结算界面。

参数页的「资源作弊」支持输入正增量发放矿物、能源、科研、资源核心、外星点和外星芯片；非法、负数或溢出输入不会更改余额。「解锁全部科技」只完成 248 个常规节点，不自动购买进阶后继。

## 工程与数值维护

当前入口为 `project.godot` → `main.tscn` → `src/Application/Main.cs`。运行时全部业务使用 C#，没有 GDScript 桥接；旧 GDScript 运行代码和一次性迁移脚本已清理，原始版本保留在受保护备份中。`.gdshader` 是 Godot 原生着色器，不是 GDScript 业务脚本。

| 目录 | 职责 |
|---|---|
| `src/Domain` | 经济、研究、机型、特性、参数与 CSV 校验 |
| `src/Combat` | 纯托管战斗、空间查询、飞行、炮火、伤害、生产维修和波次调度 |
| `src/Rendering` | 地球、云、大气、天体、建筑、批量舰队及特效 |
| `src/Presentation` | 科技画布、特性背包、HUD、观战与音效 |
| `src/Application` | 主循环、输入、界面整合、事务存档与开发验证入口 |
| `data/domain` | **50 张正式 UTF-8 CSV** 与目录结构说明 |
| `assets/managed` | 无 GDScript 的场景、网格、共享 PBR 材质和动画部件 |
| `tools` | 导入、发布、验收和离线布局维护工具 |

新手引导可复用 `src/Application/Main.GuidedFocus.cs` 中的 `PauseAndFocusUi(message, revealUi, focusUi, animateCamera, isRelevant)`：同步暂停业务，在事件结束后打开界面、定位控件并执行可选的镜头动画；运行状态已变化时丢弃过期请求。护盾节点高亮由 `ResearchGraphView.SetTutorialHighlight(id)` 控制，传空字符串清除。地表镜头可通过 `RotateEarthToDirection(localNormal, screenFractionX, durationSeconds)` 指定取景位置与动画时长。

正式游戏从 CSV 编译数值。科技值、费用、前置、说明、机型倍率、Perk 公式、敌军参数与波次构成都有对应表；字段错误或引用缺失会带来源报错，不回退到旧 JSON。表格只在启动时加载，修改后重启生效，运行中没有热重载。测试 fixture 不属于日常调数值入口。

具体表格、字段和字段规则见 [数值表编辑说明](data/domain/README.md)。科技位置由 `tools/reflow_research_graph.py` 按真实 DAG 生成；重新排版时会验证逐圈前置、拆分节点邻接和节点间隙，不改数值与费用。
