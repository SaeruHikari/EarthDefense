# 数值表入口

日常调数值从 [CSV 编辑说明](domain/README.md) 开始，全部现有表和行数见 [完整表索引](TABLE_INDEX.md)。当前包括 42 张领域表和 7 张战斗表，共 49 张 CSV。

修改完成后，双击项目根目录的 **ValidateData.bat**。检查会读取真实运行时 CSV，验证格式、数值范围、引用关系和科技依赖，不启动游戏或性能测试，不修改玩家存档。检查通过后重新启动游戏使用新表。

已有存档中的工程参数会覆盖表中的对应默认值；初始资源与设施只用于新局。详情与具体修改示例均在编辑说明中。

当前数值表是唯一正式来源，运行时没有旧 JSON 回退，缺表或坏表会直接报错。
