Embedded text-test font notices
================================

The byte arrays in embedded_text_test_fonts.cpp contain deterministic test
fonts derived from the following projects:

- Inter v4.1: Copyright 2016 The Inter Project Authors.
- Noto Sans Hebrew: Copyright 2024 The Noto Project Authors.
- Noto Sans Thai: Copyright 2022 The Noto Project Authors.
- Noto Emoji: Copyright 2013 Google LLC.
- Vazirmatn: Copyright 2015 The Vazirmatn Project Authors.

The collection and color test fonts are test-only derivatives of the Inter and
Noto Sans Hebrew assets above. All embedded font software is distributed under
the SIL Open Font License, Version 1.1.

Deterministic asset ledger
--------------------------

The embedded byte arrays, rather than a system font installation, are the
normative inputs of these tests. Their SHA-256 identities are:

- Skr Test Latin: 7454583868339bd4f6c4c692d02e33d8439f8d742bec32e8be3e5aab1646cd74
- Skr Test Hebrew: 7d419be19cf33c53abd583c5976b1402d403f26037652ebfa8f638c145be62f5
- Skr Test Arabic: 7bf5f3a70b38a597624e2b6682b3b577ad3a80795e7cf316dfebae141766c7f9
- Skr Test Thai: e911d349105040042c827c0aede77b04c7fd9393f642a4484b277150f62fbac0
- Skr Test Emoji: 8d339b6ca3e06e874f66918ad032c50960c3bd539fe84dce5ec3df0feb73b746
- Skr Test Collection: ae8a0f61925fa98738518713ea7623bcfe9dd15faa124aea57686ed941a2cda7
- Skr Test Color: 4155543403db2d35da30139e1f7c1748a0528337d1888bffc1ab30af03692424

Inter is pinned to upstream commit
e3a3d4c57d5ecc01453a575621882a384c1995a3. The Hebrew, Arabic and Thai
sources are pinned through Godot commit
549d1846bdfc0886b4696a1a76f15206364f69b0 and its thirdparty/fonts assets.
The Emoji subset is pinned to Google Fonts commit
7ff85c87f93ea6cca5f41c69f2e4edcb90240f26. The collection and color files
are test-only SFNT derivatives and carry renamed Skr Test family names.
